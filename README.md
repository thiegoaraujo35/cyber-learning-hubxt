# Cyber Learning Hub

Plataforma pessoal de gestão de aprendizagem em Cybersecurity (Next.js + Supabase).

## Rodar localmente
```bash
npm install
cp .env.example .env.local     # preencha as variáveis do Supabase
npx supabase start             # requer Docker; mostra URL e anon key locais
npm run dev                    # http://localhost:3000
```

## Estado (Etapa 1)
Estrutura, tema escuro, menu lateral, autenticação (Supabase Auth) e dashboard com estados vazios.
Páginas dos demais módulos são provisórias e indicam a etapa prevista.
